## ✨ Overview

SWIMAX is a professional academy management platform designed to streamline daily operations for swimming academies.

The system provides a clean, responsive admin dashboard to manage:

- Coaches
- Trainees
- Group sessions
- Attendance tracking
- Payroll summaries
- Live active sessions
- Dashboard analytics

Built as a real business project with polished UI/UX and responsive design.




```bash
npm run dev
```
